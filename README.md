# 💹 FinSight AI (Creative Flourish Hub)

SaaS de análise financeira com IA: chat sobre documentos (PDF), comparação de ativos, ranking, análise de sentimento e risco regulatório, com planos de assinatura.

## 🎯 Funcionalidades

- Chat com IA sobre múltiplos documentos financeiros (PDF)
- Comparação de ativos e ranking
- Análise de sentimento de mercado
- Avaliação de risco regulatório
- Briefings e relatórios automatizados
- Planos de assinatura (Pricing) e autenticação de usuários

## 🛠️ Tecnologias

`React` `TypeScript` `Vite` `Supabase` `Tailwind CSS` `IA/LLM`

## 🚀 Como executar

```bash
git clone https://github.com/henry842/creative-flourish-hub.git
cd creative-flourish-hub
npm install
npm run dev
```
